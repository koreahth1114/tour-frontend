# 청원여행사 4차 로컬 시안 — 첫 화면 구성 변경

기준 커밋 `f15c437ffca98344bb5e251d15133e21fe1b65cf`, 브랜치 `refine-navigation-local`. 사용자 요청에 따라 첫 화면의 구도를 변경했다. 운영 push·PR·배포·DB·인증·DNS 변경 없음.

## 검토

- `http://127.0.0.1:4180/review`: 직전 / 최신 시안, 360·390·768·1440px 비교.
- 최신 홈 4180, 직전 홈 4181. 이전 기록 `/review-v3`, `/review-v2`도 보존.
- 재실행: 저장소 상위 작업 폴더에서 `node qa/phase4-server.cjs`.
- 검토 서버는 GET 기반 공개 데이터 fixture와 원본 공개 사진을 사용하며, 문의·예약 쓰기 요청을 차단한다.

## 검증

- 1440px/390px 화면의 실제 픽셀을 우선 확인: 직전 시안 대비 구도 차이 명확. 360/768px도 확인했고 가로 넘침 없음.
- 네 가지 폭의 메뉴 hover·키보드·Escape·패널 진입·검색·견적 이동·출발지 필수·하단 5탭·사진 갤러리 회귀 통과. reduced motion 유지.
- 메인 2개 슬라이드의 제목·태그·상품 문구·가격·링크·이미지 경로를 전후 비교하여 동일함을 확인. 네 폭에서 다음/이전 조작, 긴 제목의 넘침 없음, 추천 영역 분리, 슬라이드 버튼 44×44px 이상을 확인.
- 현재 공개 홈페이지 설정을 GET으로 별도 읽어 메인 2개·보조 1개가 fixture와 완전히 동일함을 확인. 원본 데이터와 각 슬라이드의 상품 수를 그대로 보존.
- 설정 로드 전/빈 응답에서 사용하는 기본 슬라이드 3개도 네 폭에서 검증했다. 사용자 화면에 등장한 '남국 겨울 골프'를 포함하며 제목 넘침 없음. `qa/phase4-fallback.json` 및 1440/390px 캡처 보존.
- 상품 7개·상세 사진 9장·본문·가격·사진 경로 보존 비교 통과. pageerror 0건, 실제 문의/예약 쓰기 0건.
- Vite production build, 변경 TSX 대상 제한 ESLint, diff whitespace 검사 통과.
- 전체 타입 검사 실패는 기존 3건 그대로: ProductGrid.tsx:12 product/item props, ProductDetail.tsx:859 to 속성 2건. TypeScript 6 검사에서 기존 설정 deprecation만 `--ignoreDeprecations 6.0` 인자로 제외. 소스 설정 변경 없음.
- 실제 iOS/Android 기기와 실제 문의/예약 전송은 미실행. 로컬 읽기 fixture 검증이므로 운영 쓰기·인증 검증을 의미하지 않는다.

## 동일 조건 성능

직전 f15c437과 새 시안을 fresh Chrome context로 전후 5회 교차 측정. 1440×1000, CPU 4배 제한, RTT 150ms, 다운로드 200,000B/s, API 250ms 지연, 외부 스크립트 600ms 지연, DCL 뒤 6초 관찰. 동일 SVG 이미지 fixture(로고 원본)를 사용하며 실제 운영 사진의 LCP 검증과 다르다.

| 중앙값 | 직전 | 최신 |
|---|---:|---:|
| FCP / 통제 이미지 LCP | 2,408ms | 2,368ms |
| 로고 DOM 표시 감지 | 2,371.2ms | 2,317.3ms |
| Long task 누적 | 1,195ms | 1,109ms |
| 초기 JS+CSS 압축 전송량 | 200,749B | 201,391B |

FCP 중앙값 -40ms, 전송량 +642B(+0.32%). 실행별 FCP 범위는 직전 2,284–2,544ms, 최신 2,296–2,552ms로 겹치므로 유의한 성능 개선을 주장하지 않는다. 로고 별도 이미지 요청 0회, hero2 요청 1회 유지. 10회 모두 pageerror 0건. 추가 이미지·폰트 요청 없음.
