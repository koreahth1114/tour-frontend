# 승인된 첫 디자인의 최종 보완

기준: 첫 파란 헤더 디자인과 견적·상품 상세 개선을 배포한 b4dd527. 사용자 추가 요청에 따라 로고 정렬, 모바일 가독성, 문의 버튼과 소개문만 보완한다. 첫 디자인의 사진·문구·메뉴·섹션 순서를 유지한다.

## 변경

- Header.tsx: 기존 Tailwind 위치 변환 클래스와 중복되지 않도록 로고 앵커를 명시한다. client-design.css에서 파란 영역 자체를 기준으로 가로·세로 중앙에 배치한다. 원본 흰색 SVG를 유지한다. SVG 실제 불투명 픽셀 중심도 자산 중심과 일치한다.
- Home.tsx: 회사소개 원문을 두 문단으로 나눈다. 원문 정규화 문자열 일치 검사를 통과했다.
- client-design.css: 모바일 제목의 한국어 단어 단위 줄바꿈, 하단 탭 글자·아이콘 대비와 선택 표시를 보완한다. 맞춤견적·카카오 상담·전화 상담에 절제된 노랑/파랑 배경, 테두리, 굵기와 그림자를 적용한다. 소개문은 PC 16px/행간 1.9, 모바일 15px/행간 1.85, 최대 읽기 폭 1080px로 조정한다.
- 가격·날짜·예약 처리, 문의 전달 경로, DB·인증·DNS·운영 데이터는 변경하지 않는다.

## 동일 조건 성능 비교

이번 비교의 BEFORE는 초기 속도 개선이 이미 반영된 a0433f6이다. 최초 eab80d5 대비 개선 측정과 혼동하지 않는다. 기존 문서의 이전 실험값은 이력으로 유지한다.

Chrome 1440×1000, CPU 4배 제한, RTT 150ms, 다운로드 200,000 bytes/s, API 응답 지연 250ms, 외부 스크립트 600ms. 새 컨텍스트/캐시 없음, 로컬 gzip 서버, 일반 사진은 동일 SVG fixture, 로고는 원본 SVG. DOMContentLoaded 이후 6초 관측. BEFORE/AFTER 번갈아 각 5회 측정했고 다른 브라우저 QA를 동시에 실행하지 않았다.

## 최종 검증

- Vite production build 성공. 새 라이브러리·웹폰트를 추가하지 않았다.
- 변경 TSX 대상 제한된 ESLint 규칙 및 git diff --check 통과.
- 홈·견적 390/430/768/1440/1920px 통과: 가로 넘침 없음, 카드/슬라이더, 스크롤, 필수 출발지 및 공백 검증, 정상 입력 활성화, 모바일 키보드 축소 모킹.
- 상품 상세 390/430/768/1165/1440/1920px 통과: 상품/가격, 이미지, 일정/선택 탭 위치, 달력 가격 가독성, 하단 예약 바와 전역 메뉴 간격.
- 로고 360/390/430/475/768/1440/1920px에서 파란 영역 중심과 일치.
- 모바일 360/390/430/475px에서 제목의 ‘여행’이 분리되지 않음, 하단 메뉴 글자 12px/600 및 진한 색상 확인.
- 소개 원문 보존·두 문단·글자 크기, 3개 CTA 크기/화면 내 배치, 견적 이동을 390/768/900/1440px에서 확인.

- 실제 기기의 키보드·노치 검사는 미실행. 실제 문의·예약은 제출하지 않았고 브라우저 검증에서 비조회 요청을 차단했다.
